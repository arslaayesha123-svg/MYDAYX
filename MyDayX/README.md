\# MyDayX 💼



A \*\*Windows Desktop Application\*\* built with \*\*C# (.NET 8)\*\* and \*\*WinForms\*\* for personal finance and daily task management.


\---


\## 📋 Features



\- 🔐 \*\*Login \& Sign Up\*\* — Secure user authentication

\- 📊 \*\*Dashboard\*\* — Overview of daily income \& expenses

\- 💰 \*\*Budget Management\*\* — Track and manage your budget

\- 📈 \*\*Charts\*\* — Visual graphs of your financial data

\- 🕓 \*\*History\*\* — View past transactions

\- ⚡ \*\*Performance\*\* — Monitor your financial performance



\---



\## 🛠️ Tech Stack



| Technology | Details |

|---|---|

| Language | C# |

| Framework | .NET 8 (Windows) |

| UI | Windows Forms (WinForms) |

| Database | SQLite |

| IDE | Visual Studio |
